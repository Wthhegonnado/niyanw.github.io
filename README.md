# Nafi — Cyberpunk Realm (single-page experience)

The visitor sees the **Enter my realm** welcome screen first. Clicking the button reveals the About Me sections on the same page, without opening another HTML page.

Files:
- `index.html` — full single-page website
- `assets/profile.png` — uploaded profile image
- `assets/realm-theme.mp3` — uploaded music

Publish on GitHub Pages:
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from a branch → `main` → `/(root)` → Save.
5. Visit `https://YOUR-USERNAME.github.io`.

The music plays after the visitor clicks the play/pause button, as browsers block autoplay in many cases.
